# 🤖 Custom Robotic Arm — Software Stack (ROS 2 Jazzy + MoveIt 2)

This repository contains the complete software pipeline for a custom robotic arm built using **ROS 2 Jazzy**, **MoveIt 2**, and **RViz 2**. It covers everything from robot description modeling all the way to motion planning in simulation, and is intended for learning, research, and prototyping purposes.

The project lives entirely on the **software side** (no hardware dependency required) and demonstrates the full workflow of modern robotic development using ROS 2.

## 📌 Project Overview

This repository demonstrates a clean and reproducible pipeline for simulating a robotic arm in ROS 2 using:

✔ **URDF/Xacro** for robot modeling  
✔ **MoveIt 2** for motion planning and collision checking  
✔ **RViz 2** for visualization  
✔ **Python** for node-level execution

The pipeline is valuable for research labs, ROS hobbyists, and robotic development teams transitioning from ROS1 to ROS2 ecosystems.

## 📁 Workspace Structure

A **standard ROS 2 workspace** is used (`ros2_ws`):
**
**ros2_ws/
├── src/
│ ├── my_robot_description/ # URDF, meshes, xacros
│ ├── my_robot_moveit_config/ # MoveIt 2 configuration
│ ├── my_robot_python/ # Python ROS node(s)
├── build/ # generated by colcon
├── install/ # generated by colcon
└── log/ # generated by colcon
**

The **URDF file** used inside the stack is:



my_robot.urdf.xacro

## 🛠️ Installation

**Update system package list:

```bash**
sudo apt update


**Install ROS 2 Jazzy full desktop:**

sudo apt install ros-jazzy-desktop-full


**Install MoveIt 2 packages:**

sudo apt install ros-jazzy-moveit


**Install useful robot tools:
**
sudo apt install \
  ros-jazzy-joint-state-publisher \
  ros-jazzy-robot-state-publisher \
  ros-jazzy-xacro


**Source ROS environment:**

source /opt/ros/jazzy/setup.bash

📂 Creating the Workspace

**Create workspace:**

mkdir -p ~/ros2_ws/src
cd ~/ros2_ws/src


**Clone packages into src/ folder:**

git clone <this-repo>

**🧱 Building the Workspace**

**From workspace root:**

cd ~/ros2_ws
colcon build --symlink-install


**Source setup files:**

source install/setup.bash


**Workspace now supports ROS 2 commands.**

🧩 Robot Description Package

Package: my_robot_description

This package handles all robot modeling assets including:

✔ URDF/Xacro
✔ Collada/STL meshes
✔ TF frames
✔ RViz visualization

Typical structure:

my_robot_description/
├── launch/
│   └── display.launch.py
├── meshes/
├── urdf/
│   └── my_robot.urdf.xacro
├── package.xml
└── CMakeLists.txt

**package.xml minimal dependencies:**
<buildtool_depend>ament_cmake</buildtool_depend>
<exec_depend>robot_state_publisher</exec_depend>
<exec_depend>joint_state_publisher</exec_depend>
<exec_depend>xacro</exec_depend>
<exec_depend>urdf</exec_depend>

**CMakeLists.txt minimal:**
cmake_minimum_required(VERSION 3.8)
project(my_robot_description)

find_package(ament_cmake REQUIRED)

install(
  DIRECTORY launch meshes urdf
  DESTINATION share/${PROJECT_NAME}
)

ament_package()

🎯 MoveIt 2 Motion Planning Stack

**MoveIt enables:**

✔ IK / FK solving
✔ Collision checking
✔ Planning scene
✔ Trajectory generation

**Generating MoveIt config

Use MoveIt Setup Assistant:
**
ros2 launch moveit_setup_assistant setup_assistant.launch.py


**Load URDF:**

my_robot.urdf.xacro


**Configure:**

Planning groups

Joints & links

End effectors (optional)

Joint limits

Collision geometry

Kinematics solvers

Odometry (optional)

Export config to:

my_robot_moveit_config/


**MoveIt package contains:**

config/
launch/
srdf/
kinematics.yaml
controllers.yaml

**🐍 Python Control Node Package
**
Package: my_robot_python

Provides a control interface via ROS topics/services.

Run the Python node:

ros2 run my_robot_python main.py

**🖥️ Running RViz Visualization
**
To simply visualize robot URDF:

ros2 launch my_robot_description display.launch.py


**Loads:**

✔ TF tree
✔ Joint State Publisher
✔ RViz2 GUI
✔ Robot model

**🧠 Running MoveIt Motion Planning
**
Launch full planning demo:

ros2 launch my_robot_moveit_config demo.launch.py


This opens MoveIt in RViz enabling:

✔ Goal setting
✔ Path planning
✔ Robot motion execution

**📡 Useful ROS Commands
**
Show topics:

ros2 topic list


View TF tree:

ros2 run tf2_tools view_frames


Echo joint states:

ros2 topic echo /joint_states

**🩺 Troubleshooting**

Robot invisible in RViz

check mesh paths inside Xacro

MoveIt refuses IK

verify joint limits in URDF & SRDF

Collisions always active

redefine collision geometry → simpler shapes
